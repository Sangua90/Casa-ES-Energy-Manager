# Casa ES Energy Manager v1.0.0

This file tracks the consolidated v1.0.0 work requested by the project owner.

Planned scope:
- multi-step setup wizard (sensors, limits, forecast, battery/strategy, AI, summary)
- clear required vs optional labels/descriptions in Italian
- global energy preference: battery-first, balanced, load-first
- per-managed-device mode: AUTO / OVERRIDE / OFF
- adaptive learning for climate/inverter loads from climate entity + real power sensor
- separate minimum ON and minimum OFF times, with 20-minute defaults suitable for heat pumps
- monitored read-only loads for phase attribution
- emergency battery grid-charge controls through configurable Home Assistant scripts
- diagnostics expanded for tomorrow's real-world validation

Safety rule: measured grid/phase/inverter data always wins; forecast and AI remain advisory. Real automatic load switching stays disabled by default until dry-run validation is accepted.
